
# ⚡ Charge Buddy

**멋쟁이사자처럼 13기 중앙 해커톤 | 전기차 충전소 및 주변 상권 통합 탐색 서비스**

전기차 충전소의 위치와 충전기 상태를 확인하고, 충전 대기 시간 동안 이용할 수 있는 주변 상권 정보를 함께 제공하는 웹 서비스입니다.

## ✨ Key Features

- **Charging Station Map** — Kakao Maps 기반 충전소 위치 및 정보 확인
- **Station Search & Filter** — 충전기 유형, 이용 가능 여부 및 위치 기반 검색
- **Nearby Places** — 충전소 주변 음식점·카페 등 편의시설 탐색
- **User Reviews** — 충전소 이용 후기 작성·조회 및 좋아요
- **Review Summary** — 최신 리뷰 요약 API 연동
- **My Page** — 차량 정보 및 충전 이력 조회 UI
